# lz-string

A Lean 4 port of [lz-string](https://github.com/pieroxy/lz-string) (1.5.0),
the LZ-based compression library for JavaScript strings.

It produces the same output as the JavaScript library, so data compressed
on one side can be decompressed on the other.

## API

All functions are in the `LzString` namespace.

| Compress                                     | Decompress                                                  |
| -------------------------------------------- | ----------------------------------------------------------- |
| `compress : String → Array UInt16`           | `decompress : Array UInt16 → Option String`                 |
| `compressToBase64 : String → String`         | `decompressFromBase64 : String → Option String`             |
| `compressToEncodedURIComponent : String → String` | `decompressFromEncodedURIComponent : String → Option String` |
| `compressToUTF16 : String → String`          | `decompressFromUTF16 : String → Option String`              |
| `compressToUint8Array : String → ByteArray`  | `decompressFromUint8Array : ByteArray → Option String`      |

```lean
import LzString

#eval LzString.compressToBase64 "Hello, world!"
-- "BIUwNmD2A0AEDukBOYAmBCIA"

#eval LzString.decompressFromBase64 (LzString.compressToBase64 "Hello, world!")
-- some "Hello, world!"
```

Differences from the JavaScript API:

- JavaScript strings are sequences of UTF-16 code units, and the algorithm
  works on those. Lean strings are converted to UTF-16 internally (see
  `LzString.toUTF16` / `LzString.fromUTF16`), so output is identical, also
  for characters outside the Basic Multilingual Plane.
- `compress` returns `Array UInt16` instead of a string: its output may
  contain unpaired surrogates, which a Lean `String` cannot hold.
- Decompression returns `none` where JavaScript returns `null` (empty or
  corrupt input), and also when the result is not valid UTF-16.
- The generic `compressCore` / `decompressCore` are exposed for custom
  encodings, like `_compress` / `_decompress` in JavaScript.

## Command-line tool

```sh
lake build
echo -n "Hello, world!" | .lake/build/bin/lz-string compress
echo -n "Hello, world!" | .lake/build/bin/lz-string compress --uri | .lake/build/bin/lz-string decompress --uri
```

Formats: `--base64` (default), `--uri`, `--utf16`, `--bytes`.

## Tests

```sh
lake test
```

The test vectors in `tests/vectors.json` are generated by the reference
JavaScript implementation:

```sh
npm install lz-string@1.5.0
node tests/gen_vectors.js > tests/vectors.json
```
